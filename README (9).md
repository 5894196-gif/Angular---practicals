## How to Run the Practicals

### Prerequisites
- Node.js (v18 or higher)
- Angular CLI

### Installation
```bash
npm install -g @angular/cli
```

### Running a Practical
```bash
cd Practical-XX-Name
ng new my-app
# Copy the component files into the src/app folder
cd my-app
ng serve
```

Open your browser and navigate to `http://localhost:4200`
